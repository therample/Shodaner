## Обзор

**Shodaner** автоматизирует запросы к [Shodan](https://www.shodan.io/) — крупнейшей поисковой системе для подключённых к интернету устройств — и собирает структурированные метаданные о конкретных моделях IoT-устройств по выбранным регионам.

Вместо ручного перебора каждой комбинации «продукт × страна» через веб-интерфейс, Shodaner:

1. **Загружает** учётные данные Google из `config.json` (при первом запуске — интерактивный ввод со скрытым паролем)
2. **Авторизуется** на Shodan через ваш Google-аккаунт
3. **Итерирует** по настраиваемому списку продуктов × стран
4. **Извлекает** паттерны серийных номеров и временные метки из страниц результатов
5. **Дедуплицирует** записи по 4-символьному префиксу для снижения шума
6. **Экспортирует** всё в чистый файл `results.txt`

<br/>

| Функция | Описание |
|:--------|:---------|
| Учётные данные без правки кода | Интерактивный ввод при первом запуске, скрытый пароль, автосохранение в `config.json` |
| Мультирегиональное сканирование | Пакетный ввод ISO-кодов стран (RU, UA, US, DE...) |
| Фильтрация по продуктам | Преднастроенный список семейств камер Dahua IPC |
| Извлечение серийников | Обрезка до 10-символьного префикса для анализа паттернов |
| Расчёт возраста | Дней с момента последней индексации для каждой записи |
| Автодедупликация | Удаление дублей по 4-символьному префиксу серийника |
| Изоляция профиля | Клонирование Chrome — рабочие данные остаются нетронутыми |

> [!NOTE]
> Shodaner читает **только** данные, уже проиндексированные Shodan публично. Он не подключается к устройствам, не авторизуется на них и не эксплуатирует уязвимости.

## Как работает

**Поток данных:**

`Учётные данные (config.json)` → `ISO-коды` → `Клон Chrome` → `Google OAuth` → `Поисковые запросы` → `Парсинг SN` → `Дедупликация` → `results.txt`

<br/>

**Пайплайн автоматизации:**

| Шаг | Действие |
|:---:|:---------|
| 0 | Загрузка учётных данных Google из `config.json` (или интерактивный ввод при первом запуске) |
| 1 | Определение профиля Chrome |
| 2 | Клонирование профиля — изолированная песочница |
| 3 | Запуск Chrome под управлением Selenium |
| 4 | Переход на Shodan |
| 5 | Авторизация через Google OAuth |
| 6 | Цикл поиска — продукт × страна |
| 7 | Дедупликация префиксов → сохранение результатов |

## Установка

```bash
git clone https://github.com/therample/Shodaner.git
cd Shodaner
pip install -r requirements.txt
```

**`requirements.txt`**

```
selenium>=4.10.0
```

> [!TIP]
> Сразу после установки добавьте `config.json` в `.gitignore`, чтобы учётные данные случайно не попали в репозиторий:
>
> ```bash
> printf "config.json\nresults.txt\n" >> .gitignore
> ```

> [!WARNING]
> Версия ChromeDriver должна **точно совпадать** с версией установленного Chrome. Инструмент выдаст подробную ошибку при несовпадении.

## Конфигурация

Откройте `shodaner.py` и найдите блок настроек:

```python
# ─── Конфигурация ───────────────────────────────────────────────────────────

CONFIG_FILE = "config.json"   # Файл для сохранения почты и пароля Google

BASE_PRODUCTS = [
    'product:"Dahua IPC-C15"',
    'product:"Dahua IPC-A35"',
    'product:"Dahua IPC-K15"',
    # ... добавьте свои
]

TARGET_CODE_WORD = "Serial Number"
OUTPUT_FILE      = "results.txt"  # Файл, куда будут сохраняться результаты
```

> [!NOTE]
> `GOOGLE_EMAIL` и `GOOGLE_PASSWORD` больше **не прописываются в коде**. Учётные данные запрашиваются интерактивно при первом запуске и сохраняются в `config.json` — см. раздел [Учётные данные Google](#учётные-данные-google).

### Параметры

| Переменная | Тип | Описание |
|:-----------|:---:|:---------|
| `CONFIG_FILE` | `str` | Файл хранения учётных данных Google (по умолчанию: `config.json`) |
| `BASE_PRODUCTS` | `list[str]` | Поисковые запросы Shodan |
| `TARGET_CODE_WORD` | `str` | Ключевое слово для извлечения (по умолчанию: `"Serial Number"`) |
| `OUTPUT_FILE` | `str` | Путь к файлу результатов (по умолчанию: `results.txt`) |

### Добавление своих продуктов

Поддерживается любой валидный [фильтр поиска Shodan](https://help.shodan.io/the-basics/search-query-fundamentals):

```python
BASE_PRODUCTS = [
    'product:"Dahua IPC-C15"',
    'product:"Hikvision DS-2CD"',
    'product:"Generic P2P Camera"',
    'port:37777',
]
```

## Учётные данные Google

Вписывать почту и пароль в исходный код больше не нужно — Shodaner управляет учётными данными через файл `config.json`.

### Первый запуск

Инструмент запросит данные в интерактивном режиме:

```
┌── Настройка учетных данных Google 
│ Введите ваш Email от Google: your_mail@gmail.com
└── Введите ваш Пароль от Google (ввод скрыт): 
```

| Поле | Режим ввода |
|:-----|:------------|
| Email | Открытый ввод |
| Пароль | Скрытый ввод (`getpass`) — символы не отображаются в терминале |

Сразу после ввода данные сохраняются в `config.json` в корне проекта:

```json
{
    "email": "your_mail@gmail.com",
    "password": "ваш_пароль"
}
```

### Последующие запуски

Учётные данные загружаются из файла автоматически — повторный ввод не требуется:

```
[*] Учетные данные Google успешно загружены из сохраненного файла конфигурации.
```

Если файл повреждён или недоступен, Shodaner автоматически перейдёт к ручному вводу.

### Смена аккаунта / сброс данных

```bash
# Windows
del config.json

# Linux / macOS
rm config.json
```

При следующем запуске Shodaner снова запросит Email и пароль.

> [!WARNING]
> Пароль хранится в `config.json` в **открытом (незашифрованном) виде**. Не коммитьте этот файл в репозиторий, не пересылайте его третьим лицам и следите за правами доступа к нему.

### Базовый

```bash
python shodaner.py
```

```
└── Введите ваш Пароль от Google (ввод скрыт): 

[*] Учетные данные сохранены в файл 'config.json' для последующих запусков.

┌── Выбор регионов для сканирования 
│ Введите ISO-коды стран через запятую (например: UA, US, PL, DE)
└── Введите регионы ➔ RU, KZ, UA

[*] Выбранные регионы: RU, KZ, UA

[1/7]  Определяю профиль Chrome...
[2/7]  Клонирую профиль...
[3/7]  Запускаю Chrome...

[7/7]  Дедуплицирую префиксы...
[+]    Все элементы обработаны (145.3с)
```

**Последующие запуски** — учётные данные подхватываются из `config.json`:

```
[*] Учетные данные Google успешно загружены из сохраненного файла конфигурации.

┌── Выбор регионов для сканирования
```

## Формат вывода

Результаты добавляются в `results.txt`:

```
product:"Dahua IPC-C15" country:"RU" [Дата: 2024-01-15 | Возраст: сегодня]      -> Serial Number: ABCDEF1234
product:"Dahua IPC-A35" country:"UA" [Дата: 2024-01-14 | Возраст: вчера]        -> Serial Number: F1E2D3A456
product:"Dahua IPC-K15" country:"KZ" [Дата: 2024-01-10 | Возраст: 5 дн. назад] -> Serial Number: 123456A789
```

### Поля

| Поле | Источник | Описание |
|:-----|:--------:|:---------|
| Продукт | ввод | Исходная поисковая строка |
| Страна | ISO-код | Регион, где найдено устройство |
| Дата | Shodan | Когда запись была обновлена |
| Возраст | вычисляется | Читаемое время с момента индексации |
| Serial Number | извлечение | Первые 10 символов серийного номера |

### Метки возраста

| Метка | Значение |
|:-----:|:---------|
| `сегодня` | Проиндексировано в текущий день |
| `вчера` | Проиндексировано 1 день назад |
| `N дн. назад` | Проиндексировано N дней назад |

> [!TIP]
> Свежие записи (`сегодня` / `вчера`) с большей вероятностью отражают **активные** устройства.

## Профиль Chrome

Shodaner клонирует ваш профиль Chrome в изолированную временную директорию перед запуском.

- Рабочий профиль Chrome остаётся нетронутым
- Нет конфликтов с параллельно запущенным Chrome
- Закладки, история и расширения сохраняются в клоне
- Тяжёлые директории исключаются для скорости клонирования

<details>
<summary>Исключаемые директории при клонировании</summary>

<br/>

```
Cache, Code Cache, GPUCache, Service Worker, blob_storage,
IndexedDB, Local Storage, Session Storage, Shared Dictionary,
GrShaderCache, ShaderCache, DawnCache, commit_queue,
component_crx_cache, Crashpad, extensions_crx_cache,
Media Cache, Application Cache, File System, Extensions,
Download Service, OptimizationGuidePredictionModels
```

</details>

## Решение проблем

<details>
<summary>Chrome не запускается</summary>

<br/>

```
[x] Не удалось запустить управляемый Chrome.
```

1. Проверьте соответствие версий ChromeDriver и Chrome
2. Проверьте, не блокирует ли антивирус / EDR Selenium
3. Убедитесь в наличии прав на запись во временную папку
4. Запустите с `--verbose` для полного трейсбека

</details>

<details>
<summary>Логин не работает</summary>

<br/>

```
[x] Кнопку Google не нашёл — жду, вдруг вы кликнете сами...
```

1. Shodan мог изменить интерфейс входа — кликните вручную
2. Проверьте данные в `config.json` — при опечатке удалите файл, данные запросят заново
3. Очистите куки Shodan и повторите
4. Проверьте, не блокирует ли 2FA автоматизацию
5. Проверьте, не заблокирован ли аккаунт

</details>

<details>
<summary>config.json не читается / нужно перенастроить</summary>

<br/>

```
[!] Не удалось прочитать файл конфигурации: ... Требуется ручной ввод.
```

1. Файл повреждён или содержит невалидный JSON (лишние запятые, сломанные кавычки)
2. Файл занят другим процессом (открыт в редакторе с блокировкой)
3. Недостаточно прав на чтение/запись в директории проекта

**Решение** — удалить файл, при следующем запуске данные будут запрошены заново:

```bash
# Windows
del config.json

# Linux / macOS
rm config.json
```

</details>

<details>
<summary>Страницы грузятся медленно / зависают</summary>

<br/>

> **Причина:** ОС снижает приоритет Chrome при сворачивании окна.

1. Держите терминал и окно Chrome на переднем плане
2. Не запускайте тяжёлые задачи параллельно
3. Уменьшите количество стран
4. Проверьте стабильность интернета

</details>

<details>
<summary>Результатов нет</summary>

<br/>

```
[x] На странице результатов ничего не найдено.
```

1. Нет устройств в выбранной стране
2. Shodan не индексировал устройства этого продукта в регионе
3. Опечатка в названии продукта в `BASE_PRODUCTS`

Проверьте запрос вручную на [shodan.io](https://www.shodan.io/)

</details>

<details>
<summary>Зомби-процессы Chrome после выхода</summary>

<br/>

Shodaner автоматически завершает процессы при выходе. Если остались:

```bash
# Windows
taskkill /F /T /IM chrome.exe
taskkill /F /T /IM chromedriver.exe

# Linux / macOS
pkill -f chromedriver && pkill -f chrome
```

</details>

## Эксплуатационные заметки

> [!IMPORTANT]
> 1. **Не сворачивайте** терминал или окно Chrome во время работы
> 2. **Не запускайте** другие тяжёлые приложения параллельно
> 3. **Время сканирования** растёт линейно: больше регионов — дольше
> 4. **Free-аккаунт Shodan** может иметь лимиты — инструмент обрабатывает их автоматически
> 5. **Google 2FA** может потребовать ручного вмешательства при первом входе
> 6. **Размер окна** установлен на `800×600` для оптимального рендеринга Shodan
> 7. **Общие машины** — удаляйте `config.json` после работы, чтобы пароль не остался в системе
